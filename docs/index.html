    02 / HOW THE LINE IS HELD

    Learn once.
    Assign forward.

    This lab learns its centroids. It does not borrow fixed thresholds or a supplied Markov model. The information boundary stays visible.

    01 / FEATURES

    Look backward.

    Trailing mean and sample standard deviation use only earlier log returns. The first window is warm-up. No current or forward return chooses its own label.

    02 / FIT

    Learn the geometry.

    Compute training means and population standard deviations. Standardize both features. Run original two-means from four deterministic starts; retain the lowest fit objective.

    03 / FREEZE

    Stop learning.

    Freeze scaler and centroids at the split. Holdout rows go to the nearest centroid without refitting. Fit-period assignments use hindsight parameters and are labeled as such.

    04 / QUESTION

    Try to break the story.

    One-state noise still gets split. Flat data may occupy only one cluster. An unseen shift can be far from both centers. Two colors do not prove two economic regimes.

    03 / WHAT THIS DOES NOT SAY

    A clustering lab.
    Not a trading edge.

    No actual stock observations, performance backtest, portfolio, position, forecast, broker key or trade execution. Synthetic examples are deliberately constructed teaching controls.

    Read the exact contract ↗
    Clusters are a modeling choice
    K is fixed at two. Euclidean mean/volatility geometry, standardization, window length, initialization and fit interval shape the result. Four starts do not ensure a global optimum; outliers and tiny fit variance can dominate.
    Holdout is not a tuning license
    Changing inputs after viewing the holdout is descriptive exploration, not independent model validation. Rolling windows overlap. There are no p-values, confidence intervals, probability calibration or real-market generalization claims.
    Distance is not confidence
    The inspector reports squared nearest-centroid distance in standardized feature space. It is not a posterior probability, an economic diagnosis or a calibrated out-of-distribution test.
    Local and disposable
    All computation runs in this page. No feed, upload, storage, telemetry or paid service. Resetting inputs or closing loses state. The static host may log normal asset requests. Native Python and browser JavaScript are independent implementations.
